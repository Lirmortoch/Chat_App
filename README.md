# Chat_App
Chat application built with the PERN stack (PostgreSQL, Express.js, React, Node.js).

Features:

* User authentication (sign up, log in, and log out)
* Create, edit, and delete chats
* Send messages with images and file attachments
* Edit and delete messages
* Real-time messaging experience

## Stack
* JS (ES6+)
### Frontend
* HTML5
* CSS3
* React
* Redux 
* React Router
* Vite
### Backend
* Node.JS
* Express
* PostgreSQL
* WebSocket

## Getting Started

### Executing program
Clone repository:
```
git clone https://github.com/Lirmortoch/Chat_App.git
```

Go to backend folder. Install dependencies:
```
npm install
```
Run the server
```
npm run dev
```

Go to frontend folder. Install dependencies:
```
npm install
```
Run the server
```
npm run dev
```
